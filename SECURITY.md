# Security policy

Report vulnerabilities privately through GitHub: Security tab, "Report a vulnerability" (private vulnerability reporting). Please do not open a public issue. This is a personal project, so expect a best-effort response.

The dashboard is local-only (binds 127.0.0.1), read-only, and stores event and tool names, counts, short labels and local paths, never prompts or file contents. Reports about anything that exposes data beyond that, or lets a web page or local process change state, are in scope.
